# Numerai Research

Minimal workspace for Numerai data exploration and research.

## Structure

- `data/` — local datasets and downloaded data (not tracked by Git)
- `src/` — reusable Python source code
- `notebooks/` — exploratory Jupyter notebooks
- `outputs/` — generated research artifacts (not tracked by Git)
- `tests/` — automated tests

Modeling code will be added later.
